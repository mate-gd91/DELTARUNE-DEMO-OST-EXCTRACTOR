# DELTARUNE-DEMO-OST-EXCTRACTOR
Copies and renames the music files of deltarune demo-meaning chapter 1 and 2 - according to the names of the OST.
Works both with the deltarune demo and the full release of deltarune
**MAKE SURE TO RUN THE EXE INSIDE AN EMPTY FOLDER **
When the programm runs the first time , a .txt for the directory of DELTARUNEDEMO will be created.
Once you close the programm, add the directory (save the txt) and then rerun the programm.
Enjoy :))
